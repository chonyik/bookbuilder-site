# Statements to Books

Turn bank and credit-card statements into a set of books.

**Use it here: https://bookbuilder.adroitie.com/**

Upload statements (CSV, Excel or PDF), check how each transaction is categorized, and download an Excel workbook with a General Ledger, Trial Balance, Income Statement, Balance Sheet and Schedule C worksheet. The workbook uses live formulas, so you can keep editing it in Excel.

## Privacy

Everything runs in your browser. Your statements and transactions are never uploaded or sent anywhere. The page loads its code libraries from public CDNs (jsDelivr, cdnjs) and its fonts from Google Fonts, and that's all it fetches.

## Limits

- Cash basis only: no receivables, payables or accruals.
- Built for a sole proprietor filing Schedule C (Form 1040). The chart of accounts can be edited on the page.
- PDFs must contain text. Scanned statements aren't supported; use the bank's CSV or Excel download instead.
- US number and date formats.

The books it produces are a starting point. Have them reviewed before you rely on them for taxes or other filings.

This repository holds only the published page. Development happens elsewhere.
